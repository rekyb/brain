# Vibecoding Capstone Rules & Constraints

> [!abstract] TL;DR
> The competition requires building a practical AI agent that solves a real-world problem and clearly demonstrates at least 3 of 6 required agent concepts taught in the Google Kaggle course.

## How it works

### Core Requirements
We must demonstrate **at least 3** of the following 6 key concepts:
1. Agent / Multi-agent system (ADK) -> shown in Code
2. MCP Server -> shown in Code
3. Antigravity -> shown in Video
4. Security features -> shown in Code or Video
5. Deployability -> shown in Video
6. Agent skills (e.g., Agents CLI) -> shown in Code or Video

### The Four Tracks
We must choose one track for our project:
- **Agents for Good:** Social impact, health, education, environment.
- **Agents for Business:** Enterprise solutions, cost savings, revenue generation.
- **Concierge Agents:** Personal AI assistants for individuals/families (privacy-focused).
- **Freestyle:** Any innovative idea outside the other three.

### Deliverables
1. **Kaggle Writeup:** Max 2,500 words, including a cover image.
2. **YouTube Video:** Max 5 minutes detailing the problem, agent usage, architecture, demo, and the build process.
3. **Public Project Link:** A live demo or a public GitHub repo with a detailed `README.md`.

## Constraints & Rules
- **Team:** Max 5 members. Only 1 final submission allowed per team.
- **Tools/Data:** External tools and LLMs (like Gemini Advanced) are allowed if they meet the "Reasonableness Standard" (affordable and accessible to all).
- **Security:** Do **NOT** include API keys or passwords in the code.
- **Licensing:** If we win, the code must be open-sourced under **CC-BY 4.0** (with exceptions for commercial data/models).
