# Free App Store Keyword Research

> [!abstract] TL;DR
> A full ASO keyword research pass costs nothing: App Store autocomplete for real query phrasing, Apple Search Ads for Apple's own popularity scores, free tiers of AppFollow/Sensor Tower for validation, and incumbent 1–3★ reviews for differentiation. The signal to hunt: **high search popularity + mediocre incumbents**.

## Free tool stack (in order of usefulness)

1. **App Store autocomplete (manual)** — type seed words into the store search bar; suggestions are ranked by real search popularity. Go letter by letter ("budget a…", "budget b…"). Free, current, unfiltered.
2. **AppFollow (free tier)** — keyword search-popularity scores + review monitoring for a couple of apps.
3. **Sensor Tower / data.ai (free accounts)** — limited daily lookups; top charts, category ranks, estimated downloads. Gauges whether a niche's leaders actually get installs.
4. **AppTweak / Astro / MobileAction free trials** — 7–14 days each; chain during the intensive research phase.
5. **Apple Search Ads (free account, no spend)** — draft a campaign to see Apple's own **search popularity scores per keyword**. Closest thing to "Google Keyword Planner for the App Store". Never run the ad.
6. **Google Keyword Planner + Google Trends** — demand proxies. If nobody googles the problem, they aren't searching the App Store for it either. Trends spots rising niches.

## The workflow

1. Pick 5–10 problem areas → generate seed keywords.
2. Run each through **autocomplete** to harvest real query phrasing.
3. Check popularity via **Apple Search Ads** scores.
4. For each promising keyword, inspect the **top 5–10 ranking apps**:
   - Old/ugly apps with lots of downloads = demand with weak supply ✅
   - Few results, or only giant apps ranking loosely = possible gap ✅
   - Fresh, polished apps with great reviews = saturated ❌
5. Read the incumbents' **1–3★ reviews** — that's the differentiation list.
